## Problem

Given an array `prices` where `prices[i]` is the price of a stock on day `i`, find the maximum profit you can achieve by buying on one day and selling on a later day. If no profit is possible, return `0`.

## Two pointers

Keep `i` at the lowest price seen so far and `j` scanning forward. If a new low shows up, move `i` there; otherwise, check if selling at `j` beats the best profit found so far.

```python
def maxProfit(self, prices: List[int]) -> int:
    buy, sell = 0, 1
    max_profit = 0

    while sell < len(prices):
        if prices[sell] < prices[buy]:
            buy = sell
        max_profit = max(max_profit, prices[sell] - prices[buy])
        sell += 1

    return max_profit
```

- **Complexity:** O(n) time, O(1) space

## Running minimum

Track the lowest price seen so far as you scan once. At each day, check if selling now (at the current price) beats the best profit found so far.

```python
def maxProfit(self, prices: List[int]) -> int:
    min_price = float('inf')
    max_profit = 0

    for price in prices:
        if price < min_price:
            min_price = price
        elif price - min_price > max_profit:
            max_profit = price - min_price

    return max_profit
```

- **Complexity:** O(n) time, O(1) space
