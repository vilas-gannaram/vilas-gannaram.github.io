## Problem

Given an integer array `nums` and an integer `k`, return the `k` most frequent elements. The answer can be returned in any order.

**Example:** `nums = [1, 1, 1, 2, 2, 3]`, `k = 2` → `[1, 2]`

## Sort by frequency

Count how often each number appears using a hashmap, then sort the numbers by their count in descending order and take the first `k`.

```python
def topKFrequent(self, nums: list[int], k: int) -> list[int]:
    counts = {}

    for num in nums:
        counts[num] = counts.get(num, 0) + 1

    return sorted(counts, key=counts.get, reverse=True)[:k]
```

- `sorted(counts, ...)` iterates over the dict's keys (the numbers).
- `key=counts.get` sorts each number by its count.
- `reverse=True` puts the highest count first, and `[:k]` takes the top `k`.

- **Complexity:** O(n log n) time, O(n) space
