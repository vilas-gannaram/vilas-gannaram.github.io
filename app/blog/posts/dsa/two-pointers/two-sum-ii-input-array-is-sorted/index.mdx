## Problem

Given a 1-indexed array of integers `numbers` sorted in non-decreasing order, find two numbers that add up to `target`. Return their indices (1-indexed) as `[index1, index2]`, where `index1 < index2`. You may not use the same element twice.

## Two pointers

Since the array is already sorted, start with one pointer at each end. If the sum is too small, move `left` right to increase it; if too big, move `right` left to decrease it. If they match, you're done.

```python
def twoSum(numbers: list[int], target: int) -> list[int]:
    left, right = 0, len(numbers) - 1

    while left < right:
        current_sum = numbers[left] + numbers[right]

        if current_sum < target:
            left += 1
        elif current_sum > target:
            right -= 1
        else:
            return [left + 1, right + 1]
    return []
```

- **Complexity:** O(n) time, O(1) space
